## 🧠 Concepts Explained

### ✅ malloc()
Allocates a single block of memory of given size.

### ✅ calloc()
Allocates multiple blocks of memory and initializes all bytes to zero.

### ✅ realloc()
Resizes previously allocated memory block.

### ✅ Singly Linked List
Each node contains:
- Data
- Address of next node

Traversal is only forward.

### ✅ Doubly Linked List
Each node contains:
- Previous pointer
- Data
- Next pointer

Traversal possible in both directions.
